Sentinela Privacy Policy

This policy describes the initial version of the Sentinela application and will be revised before public distribution. Last updated: September 27, 2026.

1. What the app does

Sentinela helps observe nearby technical signals, organize context, and log checks for authorized use. It does not identify people, does not access communications content, and does not guarantee that an environment is secure.

2. Processed data

The current version can process on the device itself technical information from Wi-Fi networks, Bluetooth devices, network connections, sensors and logs entered by you. This data is used to display results, calculate indicators and maintain local history.

3. Storage and sharing

Results and history are stored locally on the device in the current version. There is no account, own server or remote synchronization planned in this version. We do not sell personal data. Any changes will be informed on this page and in the application.

4. Permissions

Some features depend on system permissions, such as approximate location for Bluetooth/Wi-Fi scans and camera for optical scanning. You can deny or revoke permissions in Android settings; in this case, the corresponding feature may not work.

5. Authorized Use

Use the application only on devices, networks and environments that you own or for which you have express authorization. Do not use the results to accuse, monitor or approach people.
